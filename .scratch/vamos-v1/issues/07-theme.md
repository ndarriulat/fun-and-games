# 07: Theme

**What to build:** Settings gets a Theme choice: Light (default), Dark, or Follow phone (prefers-color-scheme). The whole app, including each mode's own colour, looks right in both light and dark. The choice is remembered on the phone.

**Blocked by:** 06 (Language and the Settings screen)

**Status:** ready-for-agent

- [ ] Theme setting with Light / Dark / Follow phone; Light by default
- [ ] Follow phone tracks the system setting, including changes while open
- [ ] All screens and mode colours readable in both themes
- [ ] Theme persists across reloads
- [ ] App-level tests cover the setting and persistence
